HALL 04 // THE VALUE CREATION ENGINE
5-STAGE KNOWLEDGE LIFECYCLE

วงจรการสร้างคุณค่าความรู้ (The 5 Missions)

เปลี่ยนความรู้ที่หลับใหลในอดีต ให้กลายเป็นอาวุธทางความคิดสำหรับชีวิตประจำวัน

STAGE 01 // EXCAVATE ขุดค้นความรู้
1. ขุดค้นและคัดสรร (Excavate)
ค้นหาภูมิปัญญาจากประวัติศาสตร์ วิทยาศาสตร์ และบันทึกโบราณ โดยระบุแหล่งที่มาชัดเจนทุกชิ้น
STAGE 02 // DECODE ถอดรหัสข้อมูล
2. ถอดรหัสสู่กราฟ (Decode)
แปลงข้อมูลดิบให้กลายเป็นชุดโหนด (Nodes) และความสัมพันธ์ (Edges) ใน Knowledge Graph
STAGE 03 // RETELL เล่าเรื่องใหม่
3. เล่าด้วยภาษาภาพ (Retell)
ถ่ายทอดผ่านนิทรรศการดิจิทัล Visual Storytelling ที่ดูจบและเข้าใจภาพรวมได้ภายในไม่กี่นาที
STAGE 04 // CONNECT เชื่อมโยงมิติ
4. เปิดโครงข่ายความรู้ (Connect)
สำรวจผ่าน Data Booming (ระเบิดความรู้ทีละชั้น) และ Interactive Graph (แผนที่ใหญ่)
STAGE 05 // APPLY นำไปใช้จริง
5. การ์ด Everyday Takeaway (Apply)
ปิดท้ายทุกนิทรรศการด้วยคำแนะนำที่นำไปปรับใช้ในชีวิตประจำวัน ปลุกความรู้ให้เกิดประโยชน์ทันที

Data Booming

RADIAL EXPLOSION // 3 TIERS DEPTH
  • ✦ จุดเริ่มต้น: โหนดแก่นเรื่องเดียวกลางจอ ไม่รบกวนสายตา
  • ✦ เอฟเฟกต์การระเบิด: คลิกเพื่อแตกกิ่งเป็น 6–12 โหนดลูก วิ่งออกเป็นรัศมี (Radial Burst)
  • ✦ ลำดับขั้น: เจาะลึกต่อได้สูงสุด 3 ชั้น พร้อมอนิเมชันถอดรหัส
  • ✦ เป้าหมาย: สร้างความตื่นเต้น เหมาะกับมือถือและผู้ใช้ทั่วไป
FULL EXPLORATION PRODUCT 02

Interactive Graph

“แผนที่ความรู้จักรวาลฉบับเต็ม”
D3 FORCE-DIRECTED // FULL NETWORK
  • ✦ สถาปัตยกรรม: เรนเดอร์ด้วย D3 Force-Directed Canvas ลื่นไหล 60 FPS
  • ✦ ตัวกรองทรงพลัง: ตัวกรอง 6 หมวดความรู้, แถบเลื่อนเวลา (Timeline Slider) จากอดีตถึงปัจจุบัน
  • ✦ ระบบ HUD Specimen: โหนดขนาด 8–32px แสดง Specimen Label และแหล่งอ้างอิงทันที
  • ✦ Accessibility: มีมุมมองแบบ List View สำหรับมือถือ และรองรับคีย์บอร์ด
